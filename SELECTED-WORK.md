## Estimatic

**Independent full-stack project · Currently offline**

Estimatic explores cryptocurrency market data through analytics dashboards, with experimental forecasting functionality. The project brings together a Next.js / React / TypeScript frontend and a Django REST Framework backend.

The technical focus is turning market data into a usable interface while keeping data access and presentation separate. Forecasting is experimental; no prediction-accuracy or financial-performance claim is made here.

**Recognition:** first place in the computer category and the Best Project Idea award at the Allameh Helli 5 school exhibition. This is school-level recognition.

**Availability:** source is private. No public demo is linked because the product is currently offline. This overview does not grant access to the application or its source.

## Aroly

**Independent product · In development**

Aroly is a cross-platform task management project for web, Android and Wear OS. Earlier development names included Donio and Erylo.

**Technology direction:** Next.js and TypeScript for web; Kotlin and Jetpack Compose for Android and Wear OS; Cloudflare Workers and D1 for backend services.

The development scope includes task and list management, subtasks, priorities, reminders, customizable views and offline synchronization. These capabilities are at different stages of development and should not be read as a released feature checklist.

The central challenge is maintaining a coherent task model across devices, including offline edits and the smaller interaction surface of a watch.

**Availability:** no public application repository, download or verified live demo is provided here. This is an overview of work in progress, not a commercial launch announcement. The public Todo App classroom exercise is a separate project.

## Vir Browser

**Experimental desktop project · React / TypeScript / Electron**

Vir Browser explores a custom desktop browsing interface. Its implementation combines a React interface with Electron's native browser views and application-state persistence.

The technical challenge is coordinating visible browser content, tab/workspace state and the desktop interface. Local source includes a native view manager and session persistence; those are implementation areas, not a claim of production readiness or a completed security audit.

**Availability:** this page is documentation only. No public source, installer or live demo is supplied here. The project remains experimental.
