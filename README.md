# Amirparham Akhgarandooz

**Full-stack developer · Cross-platform builder · Graphic designer**

I build web interfaces and the APIs behind them, with a particular interest in dashboards, productivity tools, and software that feels considered from the first interaction. I'm an independent developer based in Iran, open to remote freelance projects with clear scope and deliverables.

[Selected work](https://github.com/Amirparham-code/Amirparham-code/blob/main/SELECTED-WORK.md) · [Public code](https://github.com/Amirparham-code/todo-app) · [Project inquiries](https://github.com/Amirparham-code/Amirparham-code/issues/new)

## What I work with

- **Web products:** React, Next.js, TypeScript and Tailwind CSS for responsive interfaces; Python, Django REST Framework, Node.js and Express for APIs, authentication and database integration.
- **Data & services:** PostgreSQL, MySQL, MongoDB and SQLite; Cloudflare Workers and D1 for edge applications.
- **Beyond the browser:** Kotlin and Jetpack Compose for Android / Wear OS experiments; React, TypeScript and Electron for desktop interfaces.
- **Design:** Adobe Illustrator, visual identities, UI design, print layouts and reusable graphic templates.

I use AI coding and research tools to support implementation, debugging and exploration, alongside source review and practical checks.
